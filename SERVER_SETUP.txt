9. TROUBLESHOOTING
================================================================================

Issue: 502 Bad Gateway
Solution: Check PHP-FPM status
  sudo systemctl status php8.3-fpm
  sudo systemctl restart php8.3-fpm

Issue: 403 Forbidden
Solution: Check file permissions
  sudo chown -R www-data:www-data /home/erp/ShopSuite/writable
  sudo chmod -R 775 /home/erp/ShopSuite/writable

Issue: Database Connection Error
Solution: Verify database credentials in .env file
  Check MariaDB is running: sudo systemctl status mariadb
  Test connection: mysql -u shopsuite -p shopsuite

Issue: White screen / No output
Solution: Check PHP error logs
  tail -f /var/log/php8.3-fpm.log
  Check writable/logs/ directory

Issue: Nginx won't start
Solution: Test configuration
  sudo nginx -t
  Check error log: tail -f /var/log/nginx/error.log

11. SECURITY RECOMMENDATIONS
================================================================================

⚠️ IMPORTANT - Before going to production:

1. Change database password:
   ALTER USER 'shopsuite'@'localhost' IDENTIFIED BY 'new_strong_password';
   Update .env file with new password

2. Set CI_ENVIRONMENT to 'production' in .env

3. Disable CI_DEBUG in .env

4. Set proper encryption key in .env

5. Configure firewall:
   sudo ufw allow 80/tcp
   sudo ufw allow 443/tcp
   sudo ufw enable

6. Install SSL certificate (Let's Encrypt):
   sudo apt install certbot python3-certbot-nginx
   sudo certbot --nginx -d yourdomain.com

7. Secure MariaDB:
   sudo mysql_secure_installation

8. Regular backups:
   Database: mysqldump -u shopsuite -p shopsuite > backup.sql
   Files: tar -czf shopsuite_backup.tar.gz /home/erp/ShopSuite
